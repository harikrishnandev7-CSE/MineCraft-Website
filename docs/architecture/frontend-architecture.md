# Frontend Architecture

- **Engine:** Vite + React 18 SPA.
- **State Management:** Redux Toolkit slices (`auth`, `challenge`, `qr`, `assembly`, `execution`, `leaderboard`).
- **Styling:** Tailwind CSS with custom neon/cyber color system.
- **Camera / QR:** `html5-qrcode` with video fallback and input mode.
- **Editor:** Syntactically focused code display and assembly drop zones.
